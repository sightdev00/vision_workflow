# P-001 Documentation Knowledge Classification

## Historical Knowledge

Contains why the system became what it is.

Examples:
- previous architecture decisions
- migration history
- known constraints
- production lessons

## Current Understanding

Contains current human interpretation of the system.

Examples:
- current architecture model
- current problem understanding
- active design direction
- unresolved questions

## Rule

Historical Knowledge is evidence for understanding.
Current Understanding is a mutable hypothesis and must not be treated as fact without evidence.
